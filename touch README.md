# Internship Tracker

A  website to track internship applications with email alerts.

## Tech Stack

Frontend: HTML, CSS, JavaScript  
Backend: Node.js, Express.js  
Database: MySQL  
API: Gmail API with OAuth 2.0  
Tools: GitHub, VS Code, MySQL Workbench



## Features
- Track applications
- Email notifications
- Dashboard UI


## Software Used:
- Visual Studio Code
- MySQL Workbench
- Google Cloud Console (for Gmail API)
- GitHub
